X,Y Plot Tool

A standalone 2-D plotter for profiles, time series and spectra: its own window, with a chart, an Object Manager (one row per series), a foldable Data Viewer, pages (tabs), and the File / Analysis / GMT / Misc menus. It is a port of Mirone's ecran.

Ways to open it:

  • from Julia, with plot (below);
  • from the 3-D viewer, Tools > X,Y plot (an empty window);
  • from a 3-D profile: right-click the profile panel > Open in X,Y plot tool;
  • by dropping (or viz-ing) a two-column table that is not geographic.

One X,Y window serves all plot calls: while one is open, a new plot call adds a page to it instead of opening a second window.

Opening the Plotter

plot is GMT.jl's plot, with GMT.jl's arguments and keywords, drawn in the interactive window. As in GMT.jl, a matrix or GMTdataset draws column 2 against column 1 only; give multicol=true to draw every further column as its own line.

using InteractiveGMT

# x, y vectors (y may be a matrix: one line per column with multicol=true)
t = collect(0:0.1:10)
fig = plot(t, sin.(t); legend="sin", xlabel="time", ylabel="amplitude")

# a matrix: column 1 = X, the others = Y series
fig = plot([t sin.(t) cos.(t)]; multicol=true)

# y alone: X = 1:length(y)
fig = plot(rand(100))

# a GMTdataset (column names become the series names) or a multi-segment vector
D = gmtread("data.txt")
fig = plot(D; multicol=true)

Keywords (GMT.jl's): legend, lc (:red, "blue", a 0–255 or 0–1 triple), lw (points), ls (:solid, :dash, :dot, :dashdot, :dashdotdot, :none for markers only, or "-", "--", ":", "-.", "-.."), pen=(width, color, style), marker (:cross, :plus, :square, :circle, :diamond), ms (cm, or a string with its unit like "6p"), mc, title, xlabel, ylabel, proj (:logx, :logy, :loglog), multicol. iGMT-only: xtime, track, trackgeog. A GMT.jl keyword the window cannot honour (region, frame, savefig, ...) is an error; use GMT.plot for a static figure.

Line plots, with examples: plot — 2-D Line Plot.

Adding Series

plot!(fig, more_data)                                   # a GMTdataset, vector of them, or matrix
plot!(fig, x, y; legend="Series 2", ls=:dash)          # or one series by hand
plot!(x, y; legend="Series 3")                          # into the current X,Y window
bar!(fig, x, y; width=0.5)                              # drawn as bars (width in x units)

Clearing

clear!(fig)

Series Properties

Right-click a series in the Object Manager: Line properties… (colour, width, style, marker; bar width for bars), Show in Data Table, Save data…, Rename…, Delete. Analysis items act on the series selected in the Object Manager.

Axes

Each page has an Axes row in the Object Manager, like the Axes row every raster has in the 3-D viewer's Scene Objects. Its checkbox draws or hides the page's axes; a click on its label (or right-click > Properties…) opens Axes properties, the same dialog the 3-D viewer uses, with GMT's own settings. On an X,Y page it sets the X and Y limits (-R), the axis labels and the annotation and grid intervals (-B), which sides are drawn and how, the frame and grid pens, the tick length, the fonts and the number format. Settings a 2-D chart cannot draw (the Z axis, 3-D, oblique and secondary annotations) are greyed out. Pages that draw their own frame (radar, polar, pie) have no Axes row. The settings are saved with the session.

Time Series

With X in Unix epoch seconds, the X axis can be labelled as dates or times. Ticks follow zoom and pan.

t = time() .+ (0:3600)
y = rand(length(t))
fig = plot(t, y; xtime=:date)            # xtime=true is the same as :date

or later:

xtime!(fig, :date_ymd)

Modes: :linear, :date (by span), :date_ymd, :time, :decyear, :doy. Same choices in Misc > Time axis (X).

Log Axes

fig = plot(x, y; proj=:logx)                        # log X
fig = plot(x, y; proj=:logy)                        # log Y
fig = plot(x, y; proj=:loglog)                      # both

or later (true = log, false = linear):

logscale!(fig; x=true, y=false)

Same in Misc > Log X axis / Log Y axis.

Stick Diagrams

feather is GMT.jl's feather: columns (x, u, v), or (x, θ, r) with rtheta=true, θ in degrees counter-clockwise from +x (GMT convention; a compass azimuth az is θ = 90 - az).

t = collect(0:0.1:10)
fig = feather(t, [cos.(t) sin.(t)])                  # vector components u, v

az  = 360 .* rand(100)
fig = feather(1:100, [90 .- az rand(100)]; rtheta=true)   # angle (from azimuth, 0 = North) + magnitude

Profiles from the 3-D Viewer

Right-click a 3-D profile > Open in X,Y plot tool, or from Julia profile_to_xyplot(fig). The profile keeps its track (lon/lat), so the magnetic model below takes its azimuth and distances from it. Redrawing the profile in the 3-D window updates the X,Y copy. From Julia, a series gets a track with plot!(p, x, y; track=(lon, lat)).

File Menu

  • New: an empty X,Y window.
  • Open… / Save…: read and write tables (through GMT).
  • Session > Open… / Save…: the whole window (pages, series, styles, axes, magnetic state) in an .igmtz session file, the same container as the 3-D viewer's sessions.
  • Plot with GMT.jl…: the current page as a GMT.jl script, in an editor, to Run, Save or run standalone.

Sound Velocity Profile

For CTD or Argo-type data: pick the Temperature (°C), Salinity and Pressure (dbar) columns and give the latitude. Sound speed comes from Chen & Millero (UNESCO 1983), depth from pressure by the TEOS-10 formula. The result is a page of sound speed (m/s) against depth (m).

Reference a Curve to Another

Click points alternately on the selected curve (red) and on a second curve (green); a right- or double-click ends picking. Right-click a red pick > Reference me: the selected curve is stretched between the picks to match the other and drawn on a new page.

Depth to Sources (Spector-Grant)

Turn the item on over a power spectrum and left-drag a frequency band: a fit line and the depth are shown live. Fit lines stay; drag their ends to edit them. Right-click a line for Slope(m/cycle) & Intercept, Bandpass Filter (applies the band to the 3-D window's grid the spectrum came from, as a new grid), Recomp Slope/Intercept and Delete this line.

GMT Menu

spectrum1d… runs GMT's spectrum1d on any column (auto-spectrum) or a pair of columns (cross-spectra): segment size, sample interval, detrend mode, wavelength axis, and the outputs X/Y power, cross power, noise power, coherency, admittance, gain and phase, each on its own page.

Magnetic Anomaly Modelling

Toolbar Geomagnetic bar code shows a strip under the chart: Start age / End age, Create Mag Bar (the polarity bar code above the chart), Synthetic RTP (a synthetic profile reduced to the pole), Parameters… (declination, inclination, spreading rate, azimuths, layer depth, distance unit, bathymetry grid, isochron list), the contamination slider, the isochron age, and Fit (moves the synthetic to its best correlation with the measured profile).

On the chart, right-click the red star > Guide me and click to give a first guess; right-click the fitted isochron > Pin-point me to keep it; right-click a kept one > Delete me.

Pages

Click + to add a page. Right-click a tab: New, Duplicate, Rename…, Copy to Page, Delete. Each page keeps its own series, axes and time mode.

Toolbar and Misc

Zoom to fit, Grid (also Misc > Grid), and Misc > Panels (shows or hides the side panels).
